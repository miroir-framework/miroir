What to look at

  • Block labels are the raw transformerType and attribute names. Sentences such as "map [list] with [function]" come with presentation hints (#507).
  • Runtime is the unmarked default; build transformers carry the mark. A transformer with no interpolation evaluates as build, so it is marked as well. The dashed outline is the default style; the marker is the alternative, chosen with a ViewParams setting in the real editor.
  • Colors: with classification as it is today, 37 of 48 transformers share the "basic" color. The mockup uses a finer split of "basic" (lists, objects, control, values, variables). Keeping it means new classification values on the TransformerDefinitions.
  • The Runner shows its form fields as parameter reporters, its templates as "set" blocks, and its query as one collapsed block.
  • Literal objects and lists (grey) with more than three entries start collapsed.
