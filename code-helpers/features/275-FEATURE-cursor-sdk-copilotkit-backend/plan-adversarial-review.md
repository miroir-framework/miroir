Today the router factory takes only `(domainController, applicationDeploymentMap)` (`copilotKitRoute.ts:44-47`; mounted at `server.ts:868` with no capabilities argument). `GET /capabilities` recomputes the snapshot per request (`server.ts:271-279`), but the CopilotKit router never sees it. Slice 2 tests in `miroir-ai` can inject a snapshot into the test harness, but production/Electron refuse has no specified wiring — same class of gap as #273 plan review P1 (UI snapshot delivery), on the **persistence** side. → Fix: extend `createCopilotKitRouter` (or a thin middleware registered in `server.ts` / `ipcServerSetup.ts` before the router) with `getProcessCapabilities()` or a startup snapshot closure; name it in Slice 2 GREEN and RED (assert refuse uses the injected/provided snapshot, not a hard-coded `{ cursor: true, mcp: true }`).

- [x] **P2** [blocker] — **Slice 6 transport path mismatches CopilotKit 1.59 request shape and today’s `resolveConfig`.** Analysis R1 and Slice 6 say POST `aiConfig.backend: "cursor"`. `resolveConfig` reads **top-level** `(req as any).body?.aiConfig` with `providerType` + `model` (`copilotKitRoute.ts:28-41`). The sidebar sends neither (`AgentsCopilotKit.tsx:33-40` — only `runtimeUrl`, no `properties`). CopilotKit **1.59.2 does support** extra payload via `<CopilotKit properties={…}>` (`@copilotkit/react-core` `CopilotKitProps.properties?: Record<string, any>`, documented as “Custom properties to be sent with the request”). Default `useSingleEndpoint` is **true** (`copilotkit-B5RsC6la.mjs`); single-route POST bodies are `{ method, params?, body? }` (`single-route-helpers.mjs:18-22`). Client `properties` become **`forwardedProps`** on agent runs (`@copilotkit/core` `runAgent({ forwardedProps: { …this._internal.properties } })`), i.e. typically `req.body.body.forwardedProps`, **not** `req.body.aiConfig`. Slice 6 is **not impossible** with 1.59 React API — use `properties={{ aiConfig: { backend: "cursor" } }}` (dynamic when pick is Cursor) — but Slice 2/6 GREEN must **re-teach `resolveConfig`** (or a dedicated `resolveBackendPick(req)`): read `req.body.body?.forwardedProps?.aiConfig?.backend` (and keep env fallback), branch before token `buildCopilotRuntime`. Slice 6 RED should assert `AgentsCopilotKit` passes `properties` (or a wrapper hook feeding it), not an unspecified “extra body” helper alone.
